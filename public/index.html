School SMC Finder

Finds each school's website (from the official CBSE record), its School Management Committee (SMC) page, the members it lists and the SMC PDF files. Download everything as Excel, and save the PDFs into a folder you choose.

Step 1 - Get the school list (only if you don't have an Excel yet)

Show me how
  1. Open the school list in Chrome or Edge, e.g. the Mumbai CBSE list.
  2. Press F12 and click the Console tab.
  3. Click Copy the code below, paste it into the console and press Enter. (If Chrome asks, type allow pasting first.)
  4. Wait. It clicks through every page by itself. Then schools.csv downloads. Use that file in Step 2.

This runs in your own browser, on that site's page, so nothing is sent to us. Check the site's Terms before collecting its list.

Step 2 - Find websites, SMC pages and PDFs

Needs a School Name column. Add Affiliation No. to get websites from the CBSE record, or a Website column if you already have them. Other columns (address, district ...) are kept.
